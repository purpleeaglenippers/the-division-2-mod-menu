## 🧩 About

**The Division 2 Mod Menu** is a curated list of The Division 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot radar, HUD notes
- **Quality-of-Life Helpers** — inventory catalog, loadout manager, overlay notes
- **Research Notes** — mission layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Checkpoint Notes — practice from any mission checkpoint
- Radar Overlay — visualize loot and objective markers
- Replay Notes — record and review mission runs
- Playback Speed — adjust study playback (0.1x to 2x)

### Wallhack
- Gear Catalog — browse weapons, gear sets, brand bonuses
- Loadout Notes — organize builds and stat priorities
- HUD Overlay — improved visibility for health and armor

### Aimbot
- Practice Mode Notes — segment study on any mission layout
- Cover Marker Notes — chain complex maneuvers in the open world
- Movement Buffer Notes — study traversal timing
